# 对背 · 托福

两个人用的托福词块本：看搭配、例句、近义词，学过的词随时能翻。词库已去掉高考和四级里的简单词。

仓库：https://github.com/luckydrag0n/duibei-tofel

## 怎么用

1. 打开网站，输入自己的昵称。
2. 点 **开始背**。每张卡片先看例句，再看搭配和近义。
3. **不太熟** / **记住了** 都会进词本，之后在 **词本** 里随时搜、随时点开。
4. 点顶上两人进度 → **创建小屋**，把小屋码发给对方。对方同样打开网站、起昵称，再 **加入**。之后就能看见彼此背了多少。
5. 手机浏览器打开后，用「添加到主屏幕」，以后点图标就能背。

两人要选自己的昵称，不要点成对方。

## 本地运行

```sh
npm install
npm run dev
```

电脑打开 http://localhost:5173/ 。手机连同一 Wi-Fi，用终端里打印的 Network 地址打开。

```sh
npm run build
npm run preview
```

词库源文件在 `scripts/raw/`（不进 git）。若要重新生成：

```sh
npm run prepare-data
```
